## Исправления по итоговой сверке

HTTP-слой получает метрики через consumer-side интерфейсы. Полная цепочка
`Recover → Tracing → Logging → Metrics → router` теперь охватывает также
ошибки разбора параметров и неизвестные маршруты. При panic до отправки
заголовков итоговый лог и метрики отражают `500`, span получает ошибку,
active requests уменьшается, лог восстановления сохраняет trace context.
Повторная запись заголовков не меняет уже выбранный статус ответа.

Добавлены тесты ошибок транзакции и идемпотентности, сохранения полей
и неизменности отклонённого перехода статуса. Исправлены четыре учебные
опечатки. README описывает ЛР2, окружение, архитектуру и телеметрию.
